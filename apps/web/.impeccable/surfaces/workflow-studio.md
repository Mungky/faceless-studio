THESIS: Production is a conversation operating a visible workflow. A template becomes connected agents, real outputs and review gates.

OWN-WORLD: Dify's editor topology inside the incumbent graphite app: full-height bounded canvas, quiet dotted working plane, compact typed node cards with outline icons, thin connected edges, violet selection and clear status text. Existing workhorse UI typography and global colors are inherited, not replaced.

STORY: Choose Arthur, Not Yet or a new template. Configure nodes on the canvas, save, start a production, give direction in chat, review exact outputs and continue through real jobs. Missing services explain the next action.

FIRST VIEWPORT: Template name and save/run actions in a compact top strip; broad canvas at center; a roughly 320px right inspector. Run mode exposes chat and artifact tabs beside the same graph. The main app sidebar remains outside. Narrow screens switch canvas/config/chat through visible tabs.

FORM: User-pinned Dify workflow editor; code-led functional adaptation, no approved visual comp and no identity reroll. The owner's explicit reference replaces the superseded exploratory seed. Node movement/selection and real running/review states are the signature interaction.
